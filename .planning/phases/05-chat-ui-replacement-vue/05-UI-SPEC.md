# Phase 5 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Scope:** Big-bang swap of the board chat UI to CopilotKit Vue v2 (`CopilotChat` + slots, `CopilotChatInput`) behind thin local wrappers; tool-call cards (default + domain renderers for shell/file/delegate); decision cards in the `#interrupt` slot (Phase 3 contract); reasoning, slash commands, stop, full history via threads; board `/ws` and old chat stack code untouched (IMPR-03 rollback). The chat regions being replaced: `ChatSidebar.vue`, the Chat tab of `TaskChatView.vue`, the Chat tab of `SessionChatView.vue`, `ConversationBody.vue`, `ConversationInput.vue`/`ChatEditor.vue`, `MessageBubble.vue`, `ToolCallGroup/ToolCallBlock.vue`, `SubagentBlock.vue`, `ReasoningBubble.vue`, `DecisionRequest.vue`. Legacy files stay alive on disk (IMPR-03); the swap is new components wired in, old code NOT deleted.

## Design System

| Property | Value |
|----------|-------|
| Tool | none — shadcn not applicable (Vue 3, not React). PrimeVue 4 (Aura preset) is the de-facto component system; CopilotKit Vue v2 supplies the chat surface |
| Preset | not applicable |
| Component library | PrimeVue 4 (Aura, design-token driven) + `@copilotkit/vue@1.66.4` (pinned exact, early-access) |
| Icon library | PrimeIcons (`pi pi-*`) + Iconify (`@iconify/vue`, `mdi:*`) — keep PrimeIcons for chat chrome parity |
| Font | `var(--p-font-family, system-ui, sans-serif)`; mono `var(--p-font-mono, ui-monospace, SFMono-Regular, Menlo, monospace)` for code/tool output |
| Theme mechanism | PrimeVue design tokens (`--p-*` CSS variables); dark mode via `.dark-mode` class on `<html>` (PrimeVue `darkModeSelector`, localStorage `railyn-dark-mode`). **New components MUST use tokens only — no hardcoded hex — except the ported semantic badge palette (see Color).** |
| Token source | `--p-content-background`, `--p-content-border-color`, `--p-text-color`, `--p-text-muted-color`, `--p-primary-color`, `--p-highlight-background`, `--p-surface-0..950` (all already in use across the app) |

**CopilotKit integration contract (from RESEARCH/ARCHITECTURE.md, Phase 1 D-09):**
- `CopilotKitProvider` mounted at app root, `runtime-url="/api/copilotkit"`, NO `publicApiKey`/licenseToken (local-first).
- All CopilotKit usage wrapped in thin local components (`src/mainview/components/chat/`) so the pinned early-access surface stays upgradeable in one file: `RailyinChat.vue` (CopilotChat + slots + all CopilotKit CSS overrides), `DecisionInterrupt.vue` (`#interrupt` slot), `tool-call-renderers/*` (`#tool-call-*` / `useDefaultRenderTool`).
- Slots used: `#interrupt`, `#tool-call-<name>` + generic `#tool-call`, `#input` (CopilotChatInput), message slots only if markdown parity requires overrides; `useInterrupt` pairs with the `#interrupt` slot; `useAgent` for programmatic control (stop via `agent.abortRun()`).
- Thread wiring: `threadId = conversation.id` (cards) / session threads (no taskId); history loads via `connect` replay (RUNR-05); thread list via the Phase 4 `threads.list` endpoint (CHAT-08; `useThreads` NOT used).

## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding, dot sizes |
| sm | 8px | Compact element spacing, card padding, list gaps |
| md | 16px | Default element spacing, card padding, bubble margins |
| lg | 24px | Section padding, header padding, input bar padding |
| xl | 32px | Layout gaps, drawer padding |
| 2xl | 48px | Major section breaks, empty-state spacing |
| 3xl | 64px | Page-level spacing (not expected inside chat regions) |

Exceptions: existing dense gaps (6px, 10px, 14px) already in use across chat chrome (session rows, tab buttons, tool-card headers, header padding `10px 14px 6px`) are carried over deliberately for density parity — do not normalize them away during the swap. Interactive controls (buttons, option rows) must keep a ≥24px effective touch height; status/unread dots stay 7px (visual, non-interactive).

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px (0.875rem) | 400 | 1.5 |
| Label | 13px (0.82rem) | 400 | 1.4 |
| Heading | 15px (0.95rem) | 600 | 1.3 |
| Code | 12.5px (0.8rem), mono | 400 | 1.5 |

Weights: exactly 2 — regular 400, semibold 600 (600 for: session/task titles, active tab, section labels, tool-card tool names, decision option labels, weight badges).

Notes: micro-labels (relative time, meta, badges) render at Label 13px with `--p-text-muted-color` differentiation. Markdown prose inside bubbles renders at Body size with 1.6 line-height (existing `:deep` parity rules for `p`, `h1–h4`, `ul/ol`, `li`, `code`, `pre` in `ConversationBody.vue` — port those rules into the CopilotChat message overrides). User/assistant meta labels "You"/"AI" preserved.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `--p-surface-50` (light, #f8fafc) / `--p-surface-950` (dark, #020617) | App background behind sidebar + chat regions |
| Secondary (30%) | `--p-content-background` with `--p-content-border-color` borders | Chat sidebar panel, thread items, tool cards, decision card, message bubbles, code block containers, input bar |
| Accent (10%) | `--p-primary-color` (Aura indigo ~#6366f1 light) | Reserved for: send/submit CTA, active tab, focus rings, unread dot, running status dot, decision "Submit Decision" button, "AI suggests" lean badge, selection/highlight background |
| Destructive | `--p-red-500` (#ef4444) | Destructive actions only (legacy delete flows in board chrome; nothing destructive in the new chat surface) |

Accent reserved for: send button, submit decision button, active tab indicator, focus ring, unread dot, "AI suggests" badge, link accents, running-status dot. Never "all interactive elements" — hover states use `--p-content-hover-background`/`--p-highlight-background`, not accent.

Semantic status palette (secondary, token-driven where available, ported hexes where they exist as badges — light and dark variants already defined in legacy components, carry over unchanged): success `--p-green-500` #16a34a (tool done, session idle→done), running `--p-blue-500` #3b82f6, waiting `--p-yellow-500` #eab308, muted `--p-text-muted-color`. Decision weight badges: critical amber (#fef3c7/#92400e, dark #451a03/#fcd34d), medium blue (#dbeafe/#1e40af, dark #1e3a5f/#93c5fd), easy green (#dcfce7/#166534, dark #14532d/#86efac) — ported verbatim from `DecisionRequest.vue`.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | **Send message** (chat input submit). Secondary CTAs: **Submit Decision** (decision card), **New session** (sidebar), **Import legacy chats** (sidebar action) |
| Empty state (thread list) | Heading: **No sessions yet** · Body: **Start a new session to begin.** (New session button remains visible) |
| Empty state (chat area) | Heading: **No messages yet** · Body: **Send a message to start, or type / to browse commands.** |
| Error state (send/run) | **Send failed — check the server log, then try again.** Inline for run errors: **Execution failed: {error}** (toast, legacy behavior) with input re-enabled |
| Error state (thread load) | **Couldn't load this conversation — try reopening it.** (connect failure; retry = reopen thread) |
| Stop / partial response | Stop is immediate and best-effort (CHAT-04): partial assistant response labeled **Stopped** — no confirmation dialog (non-destructive) |
| Destructive confirmation | none in this phase's new chat surface (delete/archive flows stay in board chrome with their existing confirmations) |
