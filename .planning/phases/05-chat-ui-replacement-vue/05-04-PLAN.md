<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| tool args/result → renderer slots | Engine-authored display data crossing into the named slot renderers — display-only contract (D-04) |
| interrupt metadata → DecisionInterrupt | Engine-authored decision payload rendered via the ported marked/mermaid pipeline |
| resume[] → /api/copilotkit | Client-submitted decision payload back to the server — validated server-side (Phase 3) |
| toolsMenu labels → input | Server-derived command names inserted into the input as text — no execution |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-01 | Tampering | XSS via tool args/result in renderers | medium | mitigate | Renderers treat args/result as display data only; output rendered as text/pre; no v-html beyond the ported marked pipeline (same profile as legacy SubagentBlock); useToolResultDisplay defensive parse |
| T-05-02 | Tampering | XSS via interrupt metadata | medium | mitigate | DecisionInterrupt renders context through the ported mermaid/marked pipeline identical to legacy DecisionRequest (accepted profile, single-user local content); questions/options rendered as component text, never v-html of raw payload |
| T-05-03 | Tampering | Resume payload tampering | low | accept | Server-side translateResumeToSubmission validation (event-bridge.ts:402-422) — malformed payloads rejected with INVALID_PAYLOAD regardless of client |
| T-05-04 | Denial of service | Abort/stop spam | low | accept | Stop is best-effort per engine (CHAT-11 hardening is v2); same-origin single user; runtime /stop idempotent |
| T-05-SC | Tampering | npm/pip/cargo installs | low | accept | Zero installs; pins locked by pins.test.ts |
</threat_model>
