## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → POST /api/legacyImport.run | untrusted request triggers a read-only scan of frozen legacy tables + atomic writes of NEW JSONL files (never touches legacy tables) |
| import module → data/threads/*.jsonl | DB-sourced rows become file content; a crash mid-import must leave no partial log that looks imported |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-05 | Tampering | importLog threadId path | high | mitigate | threadIds come from conversations.id (decimal strings) and are routed through JsonlStore.importLog → assertThreadId (THREAD_ID_RE + resolved-path containment, jsonl-store.ts:38-47) before any fs use — never a raw string-built path |
| T-04-06 | DoS | malformed legacy tool-call JSON | medium | mitigate | Defensive JSON.parse + shape checks per row; skip + count, never throw out of the per-conversation loop (WR-05 precedent, event-bridge.ts:402-422); one bad conversation cannot abort the whole import |
| T-04-07 | Spoofing | cross-origin POST to legacyImport.run | low | accept | Import is idempotent (no-op after first run), executes no engines, and is read-only w.r.t. legacy tables — lowest-impact RPC in the app; matches the existing app-wide RPC posture (research A7) |
| T-04-08 | Tampering | SQL injection via import queries | medium | mitigate | Parameterized queries only (repo pattern); the only dynamic values are conversation ids bound as `?` params; no string-built SQL |
| T-04-09 | (correctness/DoS) | partial `.jsonl.tmp` from an interrupted import | medium | mitigate | tmp+rename atomic write (Pattern 2): a crashed import leaves only a `.tmp` that list()/exists() never match — existence checks stay honest (Pitfall 5); pinned by the atomicity unit test |
| T-04-10 | (correctness) | lifecycle-invalid imported log | high | mitigate | buildThreadLog closes every opened block before RUN_FINISHED and synthesizes dangling tool results (Pitfall 6); pinned by the lifecycle-scan unit test and the restart-replay e2e — the proven cold-replay pipeline (railyin-runner.ts:149-190) is the consumer contract |
