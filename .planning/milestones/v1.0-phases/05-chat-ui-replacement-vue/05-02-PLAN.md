## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| engine tool args/result → renderers | Untrusted-by-construction display data arriving over the AG-UI wire (TOOL_CALL_ARGS/RESULT) — renderers must treat it as data, never execute it |
| interrupt.metadata → DecisionInterrupt | Engine-authored decision payload (context/questions) rendered into the card — markdown context goes through the ported mermaid/marked pipeline, same profile as legacy |
| engine command names → toolsMenu | Server-derived command registry (engine.listCommands) mapped into menu items — names become text inserted into the input |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-05-02 | Tampering | XSS via delegate prompt/result markdown | medium | mitigate | DelegateSummaryRenderer reuses the legacy `useMarkdown` (marked) pipeline — same profile as the existing SubagentBlock (accepted today); do NOT add any new v-html site beyond the ported pattern; content is single-user local engine output |
